# 삐롱이 마스코트 PNG 8장

이 폴더에는 수달 마스코트 "삐롱이" 의 감정별 PNG 파일이 들어가야 합니다.

## 필수 파일 (총 8장)

| 파일명 | 트리거 상황 | 디자인 포인트 |
|---|---|---|
| `normal.png` | 평소 (기본 상태) | 정면, 살짝 미소, 눈 반달 |
| `happy.png` | 오늘 체크 완료 | 두 팔 들고 환호, 눈 별 모양 |
| `pouting.png` | 1일 결석 | 살짝 시무룩, 눈 처짐 |
| `sad.png` | 3일 결석 | 눈물 흘리기, 입 ㅠ |
| `away.png` | 5일 결석 | 등 돌리고 토라짐, 뒷모습 |
| `angry.png` | 7일 결석 | 화남(귀엽게), 양손 허리 |
| `sleep.png` | 잠 (Settings 페이지 상단) | 누워서 자기, Z 표시 |
| `celebrate.png` | 7일 streak 달성 | 폭죽 + 점프 |

## 사양

- **권장 크기**: 256×256px (Retina 대응으로 큼직하게)
- **포맷**: PNG (투명 배경 추천)
- **그림체**: 카카오 프렌즈 느낌의 둥근 파스텔 톤, 2.5등신
- **색상 가이드**: 본체는 베이지/갈색 톤. 포인트로 분홍(`#FFB5C0`) 활용 가능
- **마스코트 종족**: 수달 (Otter) — 둥근 얼굴, 작은 귀, 통통한 몸

## 코드에서 어떻게 쓰이나

```tsx
<Image src="/bbirong/normal.png" alt="삐롱이" width={120} height={120} />
```

파일이 없으면 브라우저에서 깨진 이미지 아이콘이 보입니다.
v1.0 출시 전 8장 모두 준비 필수.
