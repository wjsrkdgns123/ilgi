## 2. 가치 제안

**메인 슬로건**: "갓생 말고 평범한 매일. 삐롱이가 매일 너를 기다려요."
**서브 카피**: "또 못 지켜도 괜찮아요. 삐롱이는 화내지 않거든요."

**차별점 4가지**:
1. 비난 없는 톤 + 마스코트 정서 연결
2. 평생 결제 14,900원 (구독 X)
3. 광고 0개
4. 무료 습관 무제한 (마이루틴 10개 한정의 정반대)

---

## 3. 경쟁 포지셔닝

```
                  강박 (Push hard)
                       │
       챌린저스 ●      │      ● 열품타
                       │
  외적 동기 ──────────┼────────── 내적 동기
                       │
                       │      ● 마이루틴
       Habitify ●      │      ★ 삐롱 ← 시장 빈자리
                       │
                  안심 (Be gentle)
```

**직접 경쟁자**: 마이루틴 (약점 4개 다 피하기 — 무료 한도, 자동결제, 긴 튜토리얼, 광고)
**간접 경쟁자**: 챌린저스 (떠난 사용자 = 우리 잠재 고객)

## 6. GTM 단계별 전략

### Phase 1: 0 → 100명 (M1~M2)
- 본인 인맥 30명 + 사전 인스타 팔로워 50명 + 커뮤니티 20명
- 예산: 0원

### Phase 2: 100 → 1,000명 (M3~M5)
- 인스타 콘텐츠 (메인)
- PH 출시 (M3)
- 마이크로 인플루언서 5~10명
- 예산: 100~200만원

### Phase 3: 1,000 → 10,000명 (M6~M12)
- 유료 광고 월 30~50만원
- 유료 플랜 도입 (M6)
- 레퍼럴 시스템
- 예산: 월 50~100만원
